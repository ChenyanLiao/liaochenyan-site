Built for real grinders, real beans, and the sensory judgment that still matters.

01 / The first-shot problem

A familiar recipe does not mean a familiar setting.

A new coffee asks even an experienced brewer to recalibrate. Bean variety, roast state, rest time, and the equipment combination all change flow, so the first shot can still be a costly guess.

A common espresso starting point is about 18 g in, 36 g out, and 25–30 seconds, close to a 1:2 brew ratio. It is a reference range many baristas use to begin dialing in, not an absolute standard for every coffee, machine, or flavor goal.

GrindDialing did not begin as a way to collect more coffee data. It began with a simpler aim: keep each extraction from disappearing, so the next decision can start with evidence rather than memory alone.

04 / Learning your grinder

It learns from the one on your counter.

It is not a fixed threshold, a rule of thumb, or a simple lookup table. Beneath the quiet interface is a structured personalized Bayesian model with sequential inference: each real extraction becomes new evidence, while probabilistic judgment is distilled into understandable guidance without discarding uncertainty. This public page describes inputs, outputs, and operating boundaries; priors, update expressions, parameters, thresholds, and recommendation strategy remain part of the product core.

The public input contract covers the selected grinder's own visible scale and physical bounds, brew method, coffee and recipe context, and validated extraction records. Calibration is kept specific to a grinder and brew method; impossible records do not become learning evidence, while unusual but plausible records are handled conservatively. Each useful record can revise the current judgment, but the final sensory decision remains with the brewer.

Public validation status (local audit, 9 August 2026): the latest documented non-StoreKit Swift regression recorded 316 passing tests, 10 explicit opt-in skips, and no failures across input bounds, brew-method separation, persistence, and interface semantics. This demonstrates implementation consistency, not real-world recommendation accuracy. Professional accuracy validation remains ongoing, so no public error, stability, or first-shot success metric and no performance guarantee is claimed.

Bean variety, roast, rest time, dose, distribution and tamping, temperature, pressure, and equipment condition all affect the result. Guidance should not be treated as a strong conclusion when a grinder's scale or zero point is unreliable, records are incomplete or implausible, or equipment has materially changed without recalibration. GrindDialing is a decision aid, not a perfect-coffee calculator.

Privacy and data boundary
