01 / ภาพรวม

ดาวน์โหลดเสร็จยังไม่ได้แปลว่าระบบพร้อมจำลอง

การเตรียมระบบโปรตีนเยื่อหุ้มผ่าน CHARMM-GUI เกี่ยวข้องกับโครงสร้างนำเข้า แบบฟอร์มในเบราว์เซอร์ งานเบื้องหลัง การดาวน์โหลด การแตกไฟล์บีบอัด และการตรวจโทโพโลยี GROMACS สัญญาณสีเขียวในขั้นตอนหนึ่งยืนยันขั้นตอนถัดไปไม่ได้

สกิลนี้บันทึกแต่ละส่วนแยกกัน: ส่งพารามิเตอร์ใดไป งานในเบราว์เซอร์หยุดตรงไหน ไฟล์ที่ดาวน์โหลดเป็นไฟล์รวมบีบอัดหรือหน้าแจ้งข้อผิดพลาด HTML และไฟล์ GRO, TOP, ITP และ MDP สอดคล้องกันหรือไม่ สกิลนี้ไม่ใช่เอนจินพลวัตตัวใหม่และไม่ใช้แทน CHARMM-GUI

02 / เหตุผลที่สร้างขึ้น

งานในเบราว์เซอร์ แพ็กเกจที่ดาวน์โหลด และโทโพโลยีล้มเหลวได้คนละจุด

หน้าเว็บอาจดูพร้อมทั้งที่ยังไม่ได้ส่ง งานเบื้องหลังอาจเสร็จแล้วแต่เบราว์เซอร์ดาวน์โหลดไม่สำเร็จ ไฟล์ชื่อ `.tar.gz` อาจบรรจุข้อผิดพลาด HTML และไฟล์ GROMACS ที่อ่านได้ไม่ได้พิสูจน์ว่าพารามิเตอร์ลิแกนด์ที่กำหนดเองเข้าสู่โทโพโลยีสุดท้ายแล้ว

สกิลนี้ไม่กลบความแตกต่างเหล่านั้นด้วยเครื่องหมายผ่านสีเขียวเพียงตัวเดียว สถานะเบราว์เซอร์ต้องมีบันทึกเบราว์เซอร์รองรับ สถานะไฟล์ต้องอาศัยการตรวจชนิดและความสมบูรณ์ ส่วนสถานะโทโพโลยีต้องตรวจองค์ประกอบ การตัดสินใจว่าระบบควรเข้าสู่ MD ระยะเก็บผลจริงหรือไม่ยังแยกไว้ให้มนุษย์พิจารณา

03 / ความสามารถ

จากโครงสร้างต้นฉบับสู่แพ็กเกจ GROMACS

  1. 01

    ตรวจสอบข้อมูลนำเข้า PDB, SDF, MOL2 และพารามิเตอร์ลิแกนด์

  2. 02

    บันทึกพารามิเตอร์เบราว์เซอร์ URL ภาพหน้าจอ และสถานะงาน

  3. 03

    ตรวจแนววางเยื่อหุ้ม ขนาดระบบ อัตราส่วนลิพิด และการตั้งค่าไอออน

  4. 04

    แยกสถานะกำลังทำงาน ค้าง งานเบื้องหลังเสร็จแล้ว และรอมนุษย์ส่งขั้นตอนถัดไป

  5. 05

    กู้การดาวน์โหลดในเบราว์เซอร์ที่หยุดชะงักโดยเก็บหลักฐานไว้

  6. 06

    แยกแยะ tar, tar.gz, หน้าแจ้งข้อผิดพลาด HTML, แพ็กเกจเสียหาย และไฟล์ที่ดาวน์โหลดไม่ครบ

  7. 07

    ตรวจสอบ GRO, TOP, ITP, MDP และองค์ประกอบของระบบ

  8. 08

    ตรวจว่าพารามิเตอร์ลิแกนด์ที่กำหนดเองเข้าสู่โทโพโลยี GROMACS สุดท้ายจริง

  9. 09

    ใช้ทะเบียนสภาพแวดล้อมเชิงโครงสร้างแยกส่วนเยื่อหุ้มโดยรวมออกจากลิพิด ไอออน โคแฟกเตอร์ และองค์ประกอบในโพรงจับที่ระบุได้จากโครงสร้าง

  10. 10

    บันทึกหลักฐานการคงท่าการจับตลอดการทำความสะอาดโครงสร้าง จัดแนว ประกอบระบบ และแปลงพิกัดขั้นสุดท้าย

  11. 11

    ตรวจไฟล์ข้อจำกัดการเคลื่อนที่ มาโคร ตารางคลายข้อจำกัดระหว่างปรับสมดุล และสถานะที่คาดไว้สำหรับระยะเก็บผลจริง พร้อมส่งต่อข้อกำหนดที่ยังไม่คลี่คลายไปยังขั้นตอนหลัง

  12. 12

    ปิด Stage 2 ด้วยการตรวจแยกแบบอ่านอย่างเดียว การล็อกอย่างชัดเจน และการตรวจสอบ Receipt 2.0 อย่างเป็นอิสระ

  13. 13

    ป้องกันการรายงานว่าพร้อมรันระยะเก็บผลจริง ทั้งที่ผ่านเพียงการตรวจไฟล์ทางเทคนิค

04 / รองรับหลายเอเจนต์

การตรวจชุดเดียวกันทำงานผ่านไคลเอนต์เอเจนต์ต่าง ๆ ได้

รุ่นสาธารณะมีอะแดปเตอร์สำหรับสภาพแวดล้อมต่อไปนี้ โดยคงรายการตรวจสอบและเงื่อนไขส่งต่อให้มนุษย์เข้าควบคุมไว้เหมือนเดิม

  • Codex
  • Claude Code
  • OpenClaw / Javis
  • Hermes Agent
  • ไคลเอนต์อื่นที่รองรับ Agent Skills

เมื่อสภาพแวดล้อมรันไม่มีการควบคุมเบราว์เซอร์หรือช่องทางให้มนุษย์รับช่วง สกิลจะหยุดที่ขั้นตอนเบราว์เซอร์ ไม่เปลี่ยนคำว่า ‘ทำไม่ได้’ ให้เป็น ‘เสร็จแล้ว’

05 / ขอบเขตทางวิทยาศาสตร์

ไฟล์ครบไม่ได้หมายถึงได้รับอนุญาตให้จำลองระยะเก็บผลจริง

การตรวจ Stage 2 ยืนยันว่าข้อมูลนำเข้า บันทึก และไฟล์ผลลัพธ์สอดคล้องกัน ไม่ได้ตัดสินว่าสถานะโปรตอน องค์ประกอบเยื่อหุ้ม หรือพารามิเตอร์ลิแกนด์เหมาะสมทางวิทยาศาสตร์หรือไม่ และไม่ได้อนุญาตให้ทำ MD เพียงเพราะโทโพโลยีผ่านการประมวลผลล่วงหน้าได้

  • ไม่ออกสถานะ Production_Approved โดยอัตโนมัติ
  • ไม่รัน gmx mdrun
  • ไม่ใช้ gmx grompp -maxwarn เพื่อซ่อนปัญหาโทโพโลยี
  • ไม่เลือกองค์ประกอบเยื่อหุ้ม สถานะโปรตอน การแบ่งส่วนโปรตีน หรือพารามิเตอร์ลิแกนด์แทนนักวิจัย
  • ไม่อธิบายโครงสร้างที่เตรียมแล้วว่าเป็นหลักฐานของตำแหน่งจับ

production_ready=false · md_execution_allowed=false · no_mdrun=trueก่อนเข้าสู่ระยะเก็บผลจริง ผู้เชี่ยวชาญยังต้องทบทวนอัตลักษณ์โมเลกุล สถานะโปรตอน พารามิเตอร์ลิแกนด์ แนววางเยื่อหุ้ม การประมวลผลโทโพโลยีล่วงหน้า และความสมเหตุสมผลของระบบทั้งหมด

06 / ที่มาและคำขอบคุณ

เกิดจากงานสร้างระบบเยื่อหุ้มที่ติดขัดจริง

ส่วนที่สิ้นเปลืองของการสร้างระบบเยื่อหุ้มมักไม่ใช่การกรอกแบบฟอร์มครั้งเดียว แต่เป็นการรู้ว่าจะทำงานยาวที่ค้างต่ออย่างไร การดาวน์โหลดที่ล้มเหลวซ่อนงานเบื้องหลังที่เสร็จแล้วหรือไม่ และแพ็กเกจที่ได้มาในที่สุดครบสมบูรณ์หรือเปล่า โครงการนี้เปลี่ยนปัญหาที่เกิดซ้ำเหล่านั้นเป็นขั้นตอนตรวจที่ดำเนินการได้

รุ่นสาธารณะเก็บเฉพาะวิธีที่นำกลับมาใช้ได้ โมเลกุลเฉพาะที่ยังไม่เผยแพร่ รหัสงานภายใน โครงสร้างส่วนตัว พาธในเครื่อง และข้อมูลรับรองการรันไม่ถูกนำเข้ารีโพซิทอรีหรือหน้านี้

พัฒนาภายใต้คำแนะนำด้านการวิจัยจาก Nian Yin และการสนับสนุนกระบวนการทำงานเชิงคำนวณจาก NianLab
